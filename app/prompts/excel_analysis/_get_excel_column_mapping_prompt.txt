MAPPING GUIDELINES
1. Primary Matching Logic
   * Perform case-insensitive comparison.
   * First, look for exact matches between Excel headers and target columns.
   * If not found, look for partial matches or semantic equivalents.
2. Synonym and Variation Handling
   * Map based on contextual similarity:
      * “Item Name”, “Material Desc.” → ItemDescription
      * “Qty”, “Count” → Quantity
      * “Unit”, “UOM”, “Measure” → Uom
      * “Sr No”, “Line ID” → S.No
      * “Details”, “Specs” → Specification
      * “Notes”, “Comments” → Remarks
3. Formatting Tolerance
   * Accept variations such as “ItemDescription”, “Item Description”, or “ITEM_DESCRIPTION”.
   * Ignore punctuation and spacing differences.
   * Allow flexible recognition for header formats like “S No.”, “Unit-of-Measure”, “QTY(kg)”.
4. Filtering and Exclusion
   * Exclude columns with purely numeric data or blank headers.
   * Ignore irrelevant columns like “Price”, “Total”, “Tax”, “Currency”, or “Vendor”.
   * Exclude any headers containing special characters, emojis, or symbols other than alphanumeric, space, dot (.), or hyphen (-).
