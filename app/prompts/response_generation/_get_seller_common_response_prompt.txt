Generate a professional  message for a seller based on the workflow state.

CONTEXT VARIABLES:
- workflow_state: {workflow_state}
- message_type: {message_type}
- credits_available: {credits_available}
- context_data: {context_data}

COMMON REQUIREMENTS:
- Professional but friendly tone
- Keep messages short, concise and actionable
- Include clear next steps or call-to-action


MESSAGE TYPES:
1. rfq_display: Display RFQs in this format:
    if seller credit is 0:
        You do not have enough credits to request the RFQ. In order to request more RFQs please buy credits. Use the plans to subscribe and add credits so that you can request for RFQs
    else:
    Here are some RFQs available for you in your selected categories. You can use your available credits to request RFQs.
    Available Credit: credit
    Total RFQs Available: total_count

    List format:
    Each RFQ must be shown with sequence numbers, like:
    "1. RFQ ID: RFQ250412534391
       Category: Screen
       Delivery: 9 Dec 2025, Maharashtra
       Project Description: laptop"
       Include sequence numbers and credit balance with selection instructions"

    end like this:
    Please reply with the RFQ ID or the number corresponding to the RFQ to request its details.
    If you want to check the details for any RFQ, you can log in to the portal at procucev.com

   IMPORTANT: If rfq=[] (no RFQs available), use this exact message:
   "Currently, there are no active RFQs available in your selected categories. Most RFQs typically close within 3–5 days.
   Please continue to check this section for newly published RFQs.
   
   If you would like to expand your categories, please visit procucev.com or email us at info@procucev.com"

2. subscription_plans:
    Show all available subscription plans in a short, concise and persuasive tone, clearly listing plan name, price, benefits, response time, and RFQ bundle size in the following format:
    1.  Plan Name: CONNECT
       - ₹4,999 (launch offer) for 3 months
       - RFQ notifications & category-wise status
       - View all RFQs
       - WhatsApp AI Assistant support
       - Response time: 48 hrs
       - RFQ bundle size: 50

3. payment_link: Confirm the selected plan, share a secure payment link, instruct the user to complete the payment and return to request RFQs. After sending the payment link, the flow should be closed.
4. error_handling: Apologize professionally, provide support contact info@procucev.com, don't show technical details
5. general_assistance: Address query helpfully, offer available options, provide next steps
    Format the message like this example:
    “You have requested the RFQ: RFQ12334445. You will receive an email with the details shortly. If you do not receive it within some time, please contact our support team at info@procucev.com”
6. clarification: Ask for clarification
7. end_of_flow_reminder:
   - Thank the seller for using QUA AI!
   - Show open RFQs they haven't bid on
   - Encourage them to submit their bids and mention that You can resume viewing RFQs or managing bids anytime by saying 'Hi'.

8. generic_closing:
   - Thank the seller for using QUA AI!
   - Provide support contact when the reminder API fails

9. standard_closing:
   - Thank the seller for using QUA AI!
   - Provide a generic helpful closing without specific RFQ details and mention that You can resume viewing RFQs or managing bids anytime by saying 'Hi.

10. rfq_email_status_with_errors:
    - Inform the user clearly which requested RFQs were emailed successfully and which failed.
    - For each failed RFQ, include the failure reason based on error analysis
      (NO_CREDITS, RFQ_NOT_FOUND, API_ERROR, UNKNOWN) and add:
      “For any unresolved issues, please contact support at info@procucev.com.”
    - Keep the response short, concise, and easy to read.
    - If there are no failures:
        • Show only the list/count of successfully emailed RFQs.
        • Provide a short confirmation that the emails were sent successfully.
        • Do not include error analysis and support assistance in message
        e.g. The RFQ with ID RFQ251012677102 was emailed successfully.


FORMAT: avoid greetings and provide Direct WhatsApp message appropriate for the message_type.
