IMPORTANT STRUCTURE:
- The extraction has TWO levels: GLOBAL fields and ITEM-SPECIFIC fields

- DO NOT extract projectDesc or division - they are auto-populated by the system

- For STRING fields (description, brand, unitofMeasures, remarks, deliveryDate, city, state, pincode):

  - Use null when the field is not provided or missing

FIELD MAPPING RULES:

GLOBAL FIELDS (extract once for all products):
- **deliveryDate**: Extract ANY date-related information - urgent terms ("asap", "urgent"), relative dates ("tomorrow", "next week"), specific dates ("12 Sept", "23/09/2025")
- **state**: Delivery state for ALL products (e.g., "Karnataka", "Maharashtra")
- **city**: Delivery city for ALL products (e.g., "Bangalore", "Mumbai")
- **pincode**: Delivery pincode for ALL products (6-digit postal code)

PINCODE IDENTIFICATION (CRITICAL):
- Indian pincodes are exactly 6 digits and typically start with 1-8 (e.g., 411043, 560001, 400001)
- When a 6-digit number appears in the message, check if it could be a valid Indian pincode:
  * Pincodes starting with 1-8 are likely valid Indian pincodes
  * Extract it as pincode even if it appears near product specifications
  * Model numbers are usually alphanumeric (e.g., "R 4109", "M34567") or have clear prefixes
- PRIORITIZE pincode extraction: If a standalone 6-digit number (starting with 1-8) appears anywhere in the message along with a date, it's very likely a delivery pincode
- Examples:
  * "valve model 4109, 411043, 27 Nov" → pincode="411043" (6-digit, starts with 4, appears with date)
  * "Type R 4109 nitrogen valve" → 4109 is NOT a pincode (only 4 digits, part of model name)
  * "product XYZ123456" → 123456 could be pincode if standalone, but likely model if attached to text

ITEM-SPECIFIC FIELDS (extract for each product):
- **description**: Product type/category (e.g., "laptop", "chairs", "printers") - keep this generic
- **quantity**: Number of units needed - ONLY extract clear quantity values. DO NOT confuse specifications/ratings with quantity! Maximum allowed quantity is 100,000 pieces/units per product.
- **unitofMeasures**: Unit of measurement - Extract the unit of measurement along with its numeric quantity if mentioned (e.g., “25 meters”, “10 kg”, “5 boxes”, “100 ml”). Use empty string ONLY if no unit is mentioned. DO NOT default to "pcs" unless explicitly stated.
- **brand**: Preferred brand name for this item (e.g., "Acer", "HP", "Dell")
- **remarks**: Technical specifications, detailed requirements, configurations for this item (e.g., "18gb RAM, 1tb SSD", "ergonomic design", "A4 printing capacity")

CRITICAL EXTRACTION RULES:

1. **Quantity vs Unit of Measures**: DO NOT confuse specs/ratings with quantity
   - "Motors 1000KV" → quantity: "", unitofMeasures: "1000KV" (1000KV is a unit of measure, NOT quantity)
   - "Batteries 5000mAh" → quantity: "", unitofMeasures: "5000mAh" (5000mAh is a unit of measure, NOT quantity)
   - "100 Motors 1000KV" → quantity: 100, unitofMeasures: "1000KV" (100 is quantity, 1000KV is a unit of measure)

2. **Unit of Measure Extraction**: Extract UOM from user's message context
   - "25 meters cables" → unitofMeasures: "25 meters", remarks: ""
   - "50kg rice" → unitofMeasures: "50 kg"
   - "100 boxes" → unitofMeasures: "100 boxes"
   - "10 laptops" → unitofMeasures: "pcs" (countable items can use pcs)
   - "motors" (no unit mentioned) → unitofMeasures: "" (empty, will be asked)

3. **Measurement vs Quantity (CRITICAL)**:
   - A measurement (meters, kg, liters, sq mtr, cubic ft, etc.) is NOT the same as quantity/count
   - "25 meters of rope" does NOT mean 25 ropes - it means ONE item measuring 25 meters
   - "2500 sq mtr vinyl" does NOT mean 2500 pieces - it means vinyl of 2500 square meters area
   - NEVER assume the measurement value is the quantity count
   - MEASUREMENT UNITS that are NOT quantity (always set quantity="" when these appear without explicit count):
     * Area: sq mtr, sq ft, square meters, square feet, sqm, sft
     * Length: meters, feet, inches, mm, cm, yards
     * Weight: kg, grams, tons, lbs, pounds
     * Volume: liters, ml, gallons, cubic meters, cubic feet
     * Capacity: mAh, KV, watts, ampere
   - If ONLY measurement is provided (no explicit count like "need 5 rolls" or "quantity 10"):
     → Set quantity to "" (empty) so system asks for actual count
     → Put measurement in unitofMeasures
   - Example: "25 meters of rope, 15 mm thick" → quantity: "", unitofMeasures: "25 meters", remarks: "15 mm thickness"
   - Example: "50kg rice" → quantity: "", unitofMeasures: "50 kg", remarks: ""
   - Example: "2500 sq mtr vinyl 7.5mm thick" → quantity: "", unitofMeasures: "2500 sq mtr", remarks: "7.5mm thick"

4. **Specifications in Remarks**: Technical details always go to remarks
   - "18gb RAM, 1tb SSD" → remarks field, NOT description
   - Keep product type (description) separate from technical details
