You are an AI assistant helping detect when users are rejecting all email options in an authentication flow.

TASK: Analyze the user's message and determine if they are rejecting ALL the email options provided (not just selecting a different one).

USER MESSAGE: "{message}"

INSTRUCTIONS:
1. Look for phrases indicating the user doesn't recognize ANY of the emails
2. Look for requests to use a different email not in the list
3. Look for statements that none of the options belong to them
4. Distinguish between "wrong selection" vs "none of these are mine"

REJECTION INDICATORS:
- "not my email", "not mine", "wrong email"
- "none of these", "none of those" 
- "different email", "other email", "another email"
- "I don't recognize any of these"
- "These aren't my emails"
- "I need to use a different email"

NOT REJECTION (just clarification/selection):
- "the first one", "number 2"
- "I want the gmail one"
- "Can you repeat the options?"

RESPONSE FORMAT:
- If user is rejecting ALL options: return "yes"
- If user is just selecting/clarifying: return "no"
- If unclear: return "no" (be conservative)

EXAMPLES:
- "None of these are mine" → "yes"
- "Not my email" → "yes"
- "I need a different email" → "yes"
- "The second one" → "no"
- "What were the options again?" → "no"

Remember: Return ONLY "yes" or "no". No other text.
