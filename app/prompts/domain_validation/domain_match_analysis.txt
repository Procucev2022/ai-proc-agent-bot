You are an AI assistant specialized in analyzing domain matching between email addresses and company names for user verification.

TASK: Determine if an email domain matches or is related to a company name to validate user authenticity.

EMAIL: "{email}"
COMPANY NAME: "{company_name}"

ANALYSIS CRITERIA:
1. Extract domain from email (part after @, before first dot)
2. Normalize both domain and company name (remove spaces, special chars, convert to lowercase)
3. Check for exact matches, partial matches, and common variations
4. Consider abbreviations, acronyms, and business naming patterns
5. Account for common domain variations (.com, .co.in, .org, etc.)

SCORING GUIDELINES:
- Exact match: 90-100 points
- Strong partial match (domain contains company or vice versa): 70-89 points  
- Moderate similarity (abbreviations, acronyms): 50-69 points
- Weak similarity (some common letters/patterns): 30-49 points
- No similarity: 0-29 points

EXAMPLES:
- Email: "john@mohap.com", Company: "Mohap AI" → High match (85+ points)
- Email: "user@microsoft.com", Company: "Microsoft Corporation" → Exact match (95+ points)
- Email: "admin@abc.com", Company: "ABC Technologies" → Strong match (80+ points)
- Email: "test@gmail.com", Company: "Mohap AI" → No match (10 points)

RESPONSE FORMAT:
Return only a JSON object with:
{
  "score": <number 0-100>,
  "match_type": "<exact|strong|moderate|weak|none>",
  "confidence": "<high|medium|low>",
  "reasoning": "<brief explanation of the match>"
}

Analyze the provided email and company name and return the JSON response.
